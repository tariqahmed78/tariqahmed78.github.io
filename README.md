# TR Tech Media

Publish articles in `_posts/YYYY-MM-DD-slug.html` with a publication timestamp (`date` with its time zone), a root-relative `permalink`, and the other front matter fields from the Nvidia article. Use a 1200 × 675 cover and a 480 × 270 thumbnail.

GitHub Pages builds the newest post into the homepage Highlighted slot. The other recent posts appear in Latest posts, and every published post is linked from Articles and included in the sitemap.
